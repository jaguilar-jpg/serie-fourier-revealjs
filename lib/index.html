Tres formas de escribir la serie

Una señal periódica $x(t)$ de periodo $T_0$, con $f_0=1/T_0$, se arma con ondas de frecuencia $n f_0$.

Con senos y cosenos $$x(t)=a_0+\sum_{n=1}^{\infty}\Big[a_n\cos(2\pi n f_0 t)+b_n\sin(2\pi n f_0 t)\Big]$$
Con amplitud y fase $$x(t)=A_0+\sum_{n=1}^{\infty}A_n\cos(2\pi n f_0 t+\phi_n)$$
Con exponenciales $$x(t)=\sum_{n=-\infty}^{\infty}c_n\,e^{j2\pi n f_0 t}$$

¿Cómo se calcula $c_n$?

$$c_n=\frac{1}{T_0}\int_{T_0}x(t)\,e^{-j2\pi n f_0 t}\,dt$$
  • Se integra en un solo periodo de la señal.
  • $c_0$ es el promedio de la señal.
  • El tamaño de $c_n$ dice cuánto hay de la onda número $n$, y su ángulo dice cuánto está corrida.
  • Si $x(t)$ es real, $c_{-n}=c_n^{*}$: por eso el espectro es simétrico.
  • Relación con las otras formas ($n\ge1$): $c_n=\dfrac{a_n-jb_n}{2}=\dfrac{A_n}{2}\,e^{j\phi_n}$

Sumando armónicos: la idea de fondo

Una onda cuadrada se forma sumando senos, uno por uno. Mira cómo la suma (azul) se pega a la cuadrada.

Cada seno nuevo (naranja) es $\dfrac{4}{\pi n}\sin(n\pi t)$, con $n=1,3,5,\dots$

Problema 1: pulso centrado

Un pulso de altura $2$ entre $t=-1$ y $t=1$, que se repite cada $T_0$.

$$c_n=\frac{1}{T_0}\int_{-1}^{1}2\,e^{-j2\pi n f_0 t}\,dt$$
$$c_n=\frac{2}{T_0}\left[\frac{e^{-j2\pi n f_0 t}}{-j2\pi n f_0}\right]_{-1}^{1}$$
$$c_n=\frac{2}{T_0\,\pi n f_0}\cdot\frac{e^{j2\pi n f_0}-e^{-j2\pi n f_0}}{2j}$$
$$c_n=\frac{2}{T_0\,\pi n f_0}\,\sin(2\pi n f_0)$$
$$c_n=\frac{4}{T_0}\cdot\frac{\sin(2\pi n f_0)}{2\pi n f_0}=\frac{4}{T_0}\,\mathrm{sinc}(2nf_0)$$

Usamos $\mathrm{sinc}(x)=\dfrac{\sin(\pi x)}{\pi x}$. Para $n=0$ el resultado es $c_0=4/T_0$: el promedio.

Pulso general y la función sinc

Con altura $A$ y ancho $\tau$, centrado en $0$, el mismo cálculo da:

$$c_n=\frac{A\,\tau}{T_0}\,\mathrm{sinc}(n f_0\,\tau)$$
  • $\mathrm{sinc}(x)=\dfrac{\sin(\pi x)}{\pi x}$, con $\mathrm{sinc}(0)=1$.
  • Vale cero en $x=\pm1,\pm2,\pm3,\dots$
  • Por eso $c_0=\dfrac{A\tau}{T_0}$: el promedio del pulso.
  • Comprobación: $A=2$, $\tau=2$ da $\dfrac{4}{T_0}\mathrm{sinc}(2nf_0)$, el Problema 1.

Tren de pulsos: muévelo tú

$$c_n=\frac{A\,\tau}{T_0}\,\mathrm{sinc}(n f_0\,\tau),\qquad f_0=\frac{1}{T_0}$$

Sube $T_0$: las líneas se juntan. Baja $\tau$: la envolvente se ensancha. Sube $N$: la suma (azul) copia mejor al pulso (gris).

Problema 2: pulso de 0 a 2

Un pulso de altura $1$ entre $t=0$ y $t=2$. Ahora no es simétrico, y aparece un truco.

$$c_n=\frac{1}{T_0}\int_{0}^{2}e^{-j2\pi n f_0 t}\,dt=\frac{1}{T_0}\cdot\frac{e^{-j4\pi n f_0}-1}{-j2\pi n f_0}$$
Truco: sacamos factor común $e^{-j2\pi n f_0}$ para que aparezca un seno $$e^{-j4\pi n f_0}-1=e^{-j2\pi n f_0}\left(e^{-j2\pi n f_0}-e^{j2\pi n f_0}\right)$$
$$c_n=\frac{e^{-j2\pi n f_0}}{T_0}\cdot\frac{e^{j2\pi n f_0}-e^{-j2\pi n f_0}}{j2\pi n f_0}$$
$$c_n=\frac{e^{-j2\pi n f_0}}{T_0}\cdot\frac{2\sin(2\pi n f_0)}{2\pi n f_0}=\frac{2}{T_0}\,\mathrm{sinc}(2nf_0)\;e^{-j2\pi n f_0}$$

Es el mismo sinc del pulso centrado, pero con un factor extra $e^{-j2\pi n f_0}$. ¿De dónde sale? De que el pulso está corrido.

Forma simplificada: el centro del pulso

$$c_n=\frac{A\,\tau}{T_0}\,\mathrm{sinc}(n f_0\,\tau)\;e^{-j2\pi n f_0\,t_c}\qquad(t_c=\text{centro del pulso})$$

Problema 2: $A=1$, $\tau=2$, $t_c=1$ → $\dfrac{2}{T_0}\mathrm{sinc}(2nf_0)\,e^{-j2\pi n f_0}$ ✓

Problema 3: dos alturas

Altura $2$ entre $0$ y $1$, y altura $1$ entre $1$ y $2$ ($T_0=4$). Se toma un área y luego la otra; cada una es un pulso de ancho $\tau=1$.

$$c_n=\frac{1}{T_0}\left[\int_{0}^{1}2\,e^{-j2\pi n f_0 t}dt+\int_{1}^{2}1\,e^{-j2\pi n f_0 t}dt\right]$$
$$c_n=\frac{2\cdot1}{T_0}\mathrm{sinc}(nf_0)\,e^{-j2\pi nf_0\left(\frac12\right)}+\frac{1\cdot1}{T_0}\mathrm{sinc}(nf_0)\,e^{-j2\pi nf_0\left(\frac32\right)}$$
$$c_n=\frac{1}{4}\,\mathrm{sinc}\!\left(\frac n4\right)\left[2\,e^{-j\pi n/4}+e^{-j3\pi n/4}\right]\qquad(T_0=4,\ f_0=\tfrac14)$$

“Techo de casa”: el triángulo

Triángulo de altura $A$ y base $T$. Integrarlo a mano es largo; existe una fórmula directa:

$$X(f)=\frac{A\,T}{2}\,\mathrm{sinc}^2\!\left(\frac{fT}{2}\right)$$

Esa es la fórmula de un solo techo. Si se repite cada $T_0$, los coeficientes son sus valores en $f=nf_0$:

$$c_n=\frac{1}{T_0}\,X(nf_0)=\frac{A\,T}{2T_0}\,\mathrm{sinc}^2\!\left(\frac{n f_0 T}{2}\right)$$

Idea: el techo sale de combinar dos rectángulos de ancho $T/2$, por eso su espectro es el de un rectángulo, al cuadrado.

Problema 4: la rampa

$x(t)=t$ entre $-1$ y $1$, repetida cada $T_0$. Aquí hay que integrar por partes.

$$c_n=\frac{1}{T_0}\int_{-1}^{1}t\,e^{-j2\pi n f_0 t}\,dt$$
Con $a=2\pi n f_0$, $u=t$ y $dv=e^{-jat}dt$: $$\begin{aligned}\int t\,e^{-jat}dt&=\frac{t\,e^{-jat}}{-ja}-\int\frac{e^{-jat}}{-ja}\,dt\\&=\frac{e^{-jat}\,(1+jat)}{a^2}\end{aligned}$$
$$c_n=\frac{1}{T_0}\cdot\frac{e^{-ja}(1+ja)-e^{ja}(1-ja)}{a^2}$$
$$c_n=\frac{2j}{T_0}\cdot\frac{a\cos a-\sin a}{a^2}\qquad(n\neq0)$$

Para $n=0$: $c_0=0$ (la señal es impar y su promedio es cero).

Problema 5: senos y cosenos

Escribir con exponenciales: $x(t)=3+2\cos(4\pi t)+3\cos(6\pi t)$. Aquí no hay que integrar.

Como $4\pi t=2\pi(2)t$ y $6\pi t=2\pi(3)t$, tenemos $f_0=1$ Hz, y usamos $\cos\theta=\dfrac{e^{j\theta}+e^{-j\theta}}{2}$:
$$2\cos(4\pi t)=e^{j2\pi(2)t}+e^{j2\pi(-2)t}\qquad 3\cos(6\pi t)=\tfrac32\,e^{j2\pi(3)t}+\tfrac32\,e^{j2\pi(-3)t}$$
$$x(t)=3+e^{j2\pi(2)t}+e^{j2\pi(-2)t}+\tfrac32\,e^{j2\pi(3)t}+\tfrac32\,e^{j2\pi(-3)t}$$
Cada exponencial es $c_n\,e^{j2\pi n t}$, así que solo se leen los números: $$c_0=3,\qquad c_2=c_{-2}=1,\qquad c_3=c_{-3}=\tfrac32$$

El espectro de líneas

Las barras son los $c_n$ del problema anterior. Quita o pon componentes y mira cómo cambia $x(t)$.

Cada par $\pm n$ aporta un coseno de amplitud $2c_n$: por eso $2\cos(4\pi t)$ y $3\cos(6\pi t)$.

Cierre: un puente hacia la transformada

Con $T_0$ muy grande queda un solo pulso, y las líneas se pegan hasta formar una curva continua: la transformada de Fourier. $$X(f)=\int_{-\infty}^{\infty}x(t)\,e^{-j2\pi f t}\,dt$$

Conclusiones

  • Una señal periódica es una suma de ondas; sus $c_n$ son el “ingrediente” de cada una.
  • Pulso: $c_n=\frac{A\tau}{T_0}\mathrm{sinc}(nf_0\tau)\,e^{-j2\pi nf_0t_c}$. Moverlo solo cambia la fase.
  • Varias áreas se suman; las rampas piden integrar por partes; el techo tiene fórmula directa.
  • Con senos y cosenos no se integra: se leen los coeficientes.
